Signing in

No password needed. DevPath has no password logins. Use either of these on the sign-in page:

  • Continue with GitHub: signs you in with your GitHub account.
  • Email magic link: enter any email address you can open, then click the link we send you.

Every new account starts as a student, so you can try a project right away.
